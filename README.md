# BT Reconnect

Приложение для Android TV / приставок / проекторов: показывает все сопряжённые
Bluetooth-устройства и подключает или отключает их по нажатию OK на пульте,
без повторного сопряжения.

- `●` подключено, `○` не подключено; в строке видно тип устройства и активные профили (A2DP, HFP, HID).
- OK на неподключённом устройстве — подключить. OK на подключённом — отключить (сопряжение сохраняется).
- Когда подключено аудиоустройство, вверху появляется секция **«Вывод звука»**: встроенный вывод
  (динамики / HDMI) и каждая подключённая колонка или наушники. OK — направить звук туда,
  `◉` отмечает текущий вывод. Bluetooth при этом не разрывается.
- Android 5.0+ (minSdk 21), без сторонних библиотек, в фоне не работает.

## Сборка APK

**Вариант 1 — GitHub, без установки чего-либо**

1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки
   (включая скрытую `.github`).
2. Вкладка **Actions** → сборка **Build APK** запустится сама (или кнопка *Run workflow*).
3. Через 2–3 минуты откройте завершённую сборку → **Artifacts** → `bt-reconnect-apk`.
   Внутри архива — `app-debug.apk`.

**Вариант 2 — Android Studio**

Откройте папку как проект → *Build → Build APK(s)*.
Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

Сборки подписываются постоянным ключом `signing.keystore` (в git не хранится; в GitHub —
секрет `SIGNING_KEYSTORE_B64`, base64 от файла), поэтому новая версия ставится поверх старой.

## Установка

- С флешки: скопируйте APK, откройте файловым менеджером на приставке,
  разрешите установку из неизвестных источников.
- Или по сети: `adb connect <ip-приставки>` → `adb install app-debug.apk`
  (нужна включённая «Отладка по USB/сети» в настройках разработчика).

## Как это работает и где может не сработать

Публичного API «подключить сопряжённое устройство» в Android нет. Приложение
вызывает скрытые методы `connect()` / `disconnect()` Bluetooth-профилей.

- **Android 5–10** — прямое подключение, тот же вызов, что делает системное меню на телефоне.
- **Android 11+** — система может требовать для `connect()` системное разрешение.
  Тогда приложение пробует запасной путь: поднимает радиоканал до устройства,
  после чего многие колонки и наушники сами поднимают звук. Это срабатывает
  не со всеми устройствами.

Выбор вывода звука устроен так же — через скрытые методы, публичного API для этого нет:

- **Android 9–10** — `setActiveDevice` профиля A2DP: выбранная колонка становится активной,
  а «встроенный вывод» — это снятие активного устройства (колонки остаются подключёнными).
  Проверено на Mi Box 4 (Android 9).
- **Android 5–8** — одновременно подключается только одно аудиоустройство; встроенный вывод
  включается через `AudioSystem.setForceUse`.
- **Android 11+** — оба способа обычно требуют системного разрешения.

Если прошивка отказала, приложение пишет об этом в строке состояния; тогда звук
переключается по-старому — отключением лишнего устройства.

Геймпады и клавиатуры обычно подключаются сами при нажатии кнопки на них;
для них приложение полезно в основном как индикатор состояния и для отключения.
